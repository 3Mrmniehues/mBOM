Connect Excel to your data

All projects, BOM lines, and orders are available as JSON in a flat, spreadsheet-friendly shape. There are two ways to connect.

1. Live web connection (recommended)

In Excel: Data → Get Data → From Other Sources → From Web, paste this URL, then Refresh any time to pull the latest.

2. Shared file

A JSON file is refreshed automatically when the app starts and stops (not on every edit). In Excel use Get Data → From File → From JSON and point it at:

Welcome to mBOM

Choose a folder on this PC where mBOM will keep your data (a single SQLite database). The app files can live in a shared/SharePoint folder, but your data stays here, under your control.

Data folder

A local, non-synced folder (or an SSD) is safest. You can use a OneDrive folder to back it up, but editing the same database on two PCs at once via cloud sync can cause conflicts. You can change this later from Data Location.
